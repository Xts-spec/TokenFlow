# Qoder 显式切换账号验证

本次只处理 Qoder / Qoder IDE 的本机账号切换，以及重复的“本机未登录”提示。

- 原问题：先前的切换备份把“恢复原登录”的身份限制也施加到新切换。当前已退出或手动换过账号时，即使明确选择新账号也被拒绝。IDE 还会被旧 prepared 记录阻止。
- 修复：显式新切换允许覆盖可读取的其他账号或退出状态，无需先恢复；继续保留第一次原登录备份。独立的恢复操作仍禁止覆盖其他外部账号。
- 已知 schemaVersion 1 的空 Qoder 退出记录按退出状态识别；无法解析的数据不会被当作退出。
- 仍要求授权通过官方身份校验，并继续核验最新 revision、客户端进程、登录锁或 SQLite 事务。写入失败时只回滚本次拥有的数据。
- 移除重复的“本机未登录”文字，保留读取失败和实际操作错误。

验证：

- 新回归测试先复现 6 个失败场景，再应用修复。
- 59 个相关测试通过，包括两个客户端经 API 从其他账号/退出状态直接切换、旧 revision 拒绝、备份恢复及持久化故障回滚。
- 类型检查、构建通过；隔离 Electron 界面验证退出状态下可直接点击“切换到此账号”，且没有“本机未登录”提示。
- 10.15.26.52 macOS arm64 包内运行时测试通过，包含 IDE 切换、还原和两个 Qoder 客户端隔离。
- 尚未替换正在运行的应用：更新前观察到用户正在操作“Claude Desktop 使用的模型”选择窗口，未继续退出或覆盖应用。未替用户执行任何真实账号切换。
