# Qoder、Trae、ZCode 账号修复验证

范围仅限本次报告的账号展示、独立授权兼容、本机导入及 Qoder IDE 切换问题。

## Qoder 授权合并

- 相同官方 UID 展示为一个账号；独立授权文件保留。不同 UID 即使邮箱相同也不合并。
- 调用选择已启用、未确认失效且支持所选模型的授权；可恢复的访问令牌由官方刷新流程处理。
- 同等可用时比较已记录的授权、刷新或令牌签发时间；Qoder 文件修改时间不参与授权新旧排序。
- 授权明细只公开来源、状态和时间，不公开令牌。没有官方时间的旧记录显示“未知”。
- 已过期、官方返回 invalid_grant、模型仅由备用授权支持、旧账号 ID 固定路由等情况有回归覆盖。
- 验证真实账号的隔离副本：6 份 Qoder 授权归为 3 个账号，模型目录分别返回 15、15、2 个模型。未修改原账号池文件。

## 本机导入和客户端切换

- Qoder IDE 退出检测验证实际 bundle 和主程序/渲染进程，忽略退出后残留的 crashpad；TokenFlow 加解密子进程不再激活应用。
- 安装包隔离测试覆盖 Qoder IDE 切换、还原及独立 Qoder 客户端互不覆盖；未强制结束真实 IDE。
- Trae 已过期回调必须刷新成功才能保存，过期的访问和刷新授权不会被当成新授权。
- 实际 Trae 池的 5 份记录都是同一旧授权，访问和刷新期限均已过期。未获得新有效授权前不显示可调用模型。
- ZCode 本机 OAuth 按原客户端的精确账号、地区、非团队项目范围换取项目调用令牌；保留 OAuth 供同一授权续期。
- 项目令牌的目录来自当前官方客户端配置，未知目录不使用静态型号回填。
- 实际本机 GLM 账号与已有 Z.AI 账号不是同一 UID/地区。本机资料没有返回邮箱，不挪用其他账号的邮箱。
- 实际本机项目令牌接口返回空内容，导入如实报错；未证明可以推理。已有 Z.AI 账号能读到 2 个目录模型，套餐资格仍以官方响应为准。
