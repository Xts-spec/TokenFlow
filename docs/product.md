# token-flow 产品与优化说明

本文描述 2026-10-12 的源码能力，面向使用者与项目介绍。操作路径见 [使用指南](usage.md)，验证情况见 [本次发布记录](release-2026-10-12.md)。历史 P0 / P1 / P2 文档保留当时的范围，不能直接当作当前界面说明。

## 产品定位

token-flow 把“我能用哪些模型”和“在哪个 Agent 中使用”连起来：先管理授权账号与 API 来源，再给本地 Agent 分配模型，或给其他应用生成单独的 Key。运行在本机，不需要迁移日常开发工作到新的聊天客户端。

它适合有多个模型账号、多个 API 项目，或需要在不同开发客户端使用同一批模型的人。收益是集中管理来源、减少手工修改配置、明确权限和调用证据，并保留撤回接入的路径。

## 当前功能全览

| 能力 | 当前实现与入口 |
| --- | --- |
| 来源授权 | **账号授权** 按平台管理多个账号、浏览器 / 设备码授权、支持来源的本机导入、启停和删除。 |
| 原生登录 | Codex、Claude、Antigravity 的本机登录切换、原状态备份与恢复；Codex 网关切回官方有专用受控流程。 |
| 模型及额度 | 来源模型目录、账号额度窗口与失败提示，平台独立刷新；额度查询失败不直接删除授权。 |
| 多 API | **API 接口** 保存多个独立名称、入口、密钥及模型；同协议多项目，三种协议识别，首模型最小验证。 |
| 模型选择 | 搜索平台 / 账号 / 模型、展开来源卡片、共享额度、最近使用、多选与默认模型。 |
| Agent 接入 | **本地 Agent** 自动配置 Codex、Claude Code、WorkBuddy、Qoder 独立应用，更新模型菜单和受管 Key。 |
| 接入撤回 | 写前备份、外部修改检测、配置复读、恢复原配置；原生登录备份与接口备份分别维护。 |
| 重启生效 | 修改后弹窗，稍后重启；Claude Code 支持 VS Code 或选定终端会话。实际平台支持以界面为准。 |
| API 代理 | **API 代理** 为不同应用创建 Key，名称 / 用途、按来源绑定的模型权限、详情 / 复制、权限编辑、启停 / 删除。 |
| 统一协议 | `/v1` 提供 Responses、Chat Completions、Messages 与相关模型 / 压缩入口，原生直转或 sidecar 转换。 |
| 会话连续性 | 历史续接、上下文压缩、近期消息 / 工具链保留；受管 Codex 本机压缩历史恢复及切回官方迁移。 |
| 维修对话 | 常驻维修师傅、来源选择、检查工具、预检与执行证据，收起保留输入和会话，独立停止。 |
| 配置维修 | 无需模型生成四类 Agent 的具体修改方案，人工批准后备份、写入、复查及旧 Key 撤销。 |
| 备用维修 | 主应用仍运行而 sidecar 停止时，可明确选择已保存的原生 Responses API；每次运行内部预算 32,000 tokens。 |
| 活动 | 本次运行请求数、失败、tokens、最近请求和状态；受管备份中的切换记录。 |
| 设置 | 网关启动 / 停止 / 重启、额度刷新、运行日志、问题反馈。 |

后端另外保留独立本地诊断、最多 50 条持久化诊断 / 升级记录、受限网络可达检查和 npm 全局 Codex CLI 升级适配器。当前简化维修界面没有完整独立诊断和升级检查入口，不能将后端已有能力介绍为已可直接点击使用的完整流程。旧浏览器任务运行时仍在源码中，但已退出当前主界面。

## 已完成的优化及作用

### 更容易找到账号、接口和模型

| 优化 | 用户可感知的变化 |
| --- | --- |
| 导航重整 | 主导航固定为账号授权、API 接口、本地 Agent、API 代理，活动与设置置于底部。来源管理与使用位置更清楚。 |
| 平台与账号标签 | 只展示当前选中平台 / 账号；刷新放到平台标题旁，切平台不误发起授权。 |
| 本地加载图标和字体 | 来源识别更直观，界面不依赖远程字体请求。 |
| API 卡片及详情 | 查看状态、地址、支持模型和 tokens；模型列表可复制，多个接口更易区分。 |
| API 多模型输入 | 逐项添加 / 移除，逗号输入兼容，格式错误先在本地提示，协议自动检测。 |
| 名称独立修改 | 改备注无需重新验证，也不消耗额外模型额度。 |
| 来源卡片模型选择 | 先看账号共享额度再展开模型，避免将每个模型误当成独立额度。 |
| 搜索与最近使用 | 查厂商、账号或模型，快速重新选用，保留取消操作前配置。 |
| 跨来源多选 | 为同一个 Agent 配多个模型；同模型 ID 不会同时绑到两个账号，默认切换保留其余选择。 |
| 布局与反馈 | 窄窗口排版、可键盘操作的标签 / 弹窗、固定标题区、右上角提示不挤动内容，提示可关闭且悬停暂停消失。 |

### 接入后更可控，切换更连续

| 优化 | 实际作用 |
| --- | --- |
| Agent 模型菜单 | Codex 写入专用模型目录；Claude Code 写入多模型菜单及发现开关；WorkBuddy / Qoder 更新自定义模型。 |
| 受管模型路由 | 单模型受管连接可把已有会话旧模型 ID 路由到当前选择；多模型连接按已授权模型分流，来源固定。普通导出 Key 仍严格限制模型权限。 |
| 原生账号切回 | Codex 先核对完整凭据，再恢复原接口并切登录；允许正常模型变化，其他接口修改仍检测冲突。 |
| 子智能体默认值 | Codex 接入时备份并移除全局及当前旧 profile 的固定子模型 / 思考强度，使新派发继承主模型；恢复时还原默认值。显式派发和自定义 Agent 文件仍有自身优先级。 |
| Codex 上下文恢复 | 从本机记录恢复外部压缩上下文，受管 Key 轮换后仍可续接；无法恢复给出明确提示，避免清空会话。 |
| 压缩记录迁移 | 切回官方需要处理记录时先要求退出 Codex，再备份迁移；失败保留原始记录。 |
| Claude 别名兼容 | 客户端保存等价模型别名时不误报配置坏了；辅助模型或权限字段真变化仍提示核对。 |
| 配置维修入口 | 模型调用不了也可生成明确配置修改方案，预览接口 / Key / 模型，写前备份并拒绝审批后的外部变化。 |
| 重启与终端会话 | 保存后提示加载配置，可稍后处理；终端 Claude Code 针对选定会话处理，避免无差别结束其他任务。 |

### 协议与来源兼容更准确

| 优化 | 实际作用 |
| --- | --- |
| 独立来源路由 | API 模型 ID 包含来源，同名模型不会串项目；原生请求保留字段，转换请求也走对应来源 relay。 |
| 共用 Responses 归一层 | Qoder / WorkBuddy 请求和流事件归一后转 Messages / Chat，保留工具、输出上限及用量；使用协议编解码器不代表调用额外 Codex 账号。 |
| 长工具名映射 | Chat 来源的工具名超过 64 字节时稳定缩短，返回时恢复；历史及强制工具选择同步映射，参数和调用 ID 保留。 |
| WorkBuddy / Claude Code 兼容 | 只转换已知固定身份介绍为 Claude Code print / SDK 介绍，保留任务、安全、工具、权限和用户消息；来源仍可能拒绝。 |
| 真实错误分类 | 请求参数错误按 400 返回，渠道拒绝和网络 / 空流错误分别记录，不误当成账号暂不可用。11128 等来源拒绝不自动删指令或重复登录。 |
| 超时、取消与断流 | 读取和测试可取消，写超时不盲重试；异常断流记录失败，取消关闭上游，缺失用量不伪造结算。 |

### 授权、用量和恢复更清楚

| 优化 | 实际作用 |
| --- | --- |
| 独立客户端 Key | 源密钥不直接分发给 Agent，每个 Key 只用授权来源 / 模型，新增来源不自动放宽权限。 |
| 原 Key 权限修改 | 多选增加 / 移除权限，保留 Key 身份、用途及累计用量；清空后立即拒绝模型调用。 |
| 安全存储和显式显示 | 按来源 / 版本保存加密密钥，列表隐藏；本机鉴权后的显示接口只在用户操作时读取，关闭编辑清空显示状态。 |
| 私有 relay | 回环监听、单独凭据、固定协议路由、限制请求尺寸 / 空闲时间、不跟随重定向；sidecar 配置不保存上游 Key。 |
| 依赖影响提示 | 修改 / 停用正在使用的来源需确认，删除有引用来源被阻止；不静默换账号。 |
| 用量证据区分 | 本次运行活动、模型统计、同平台合计、Key 累计、来源额度分别呈现，未知不冒充成功。 |
| 备用维修限制 | 显式选原生 Responses，跳过 sidecar 但保留 `/v1` 鉴权、预算及记录，不给普通 Key 增加旁路。 |
| 迁移与备份 | 旧 API 迁移先备份并保留旧配置，失败提示，避免重复导入；配置恢复不等于软件可回滚。 |

## 兼容与实现边界

- 上游有授权适配，不表示所有套餐、模型、工具、图片、结构化输出和客户端组合均验证通过。
- Cursor SDK 来源与 Cursor 客户端接入是两个方向；后者的远程入口需要公开可达 HTTPS，应用不自动发布网关。
- Claude Code 的主模型 / 辅助模型配置一致，不证明 Auto Mode 审批分类器可用；维修审批与客户端审批独立。
- 来源拒绝某次请求不等于整个客户端渠道不可用，应比较会话、客户端版本、工具和上下文。
- npm Codex CLI 升级适配器仅覆盖可核对的 macOS / Linux npm 全局安装；方案固定版本、10 分钟有效，人工批准、指纹及进程检查，不能套到桌面版、IDE、Homebrew 或未知安装。没有通用 Shell 执行入口。
- 本地诊断不依赖模型或 sidecar，但主应用及本机权限服务仍需运行；HEAD 可达不证明模型权限有效。
- 连接图、完整厂商兼容矩阵、连接方案收藏、更多安装通道和细分网络阶段测量尚未交付。

## 对外可复用介绍

> token-flow 是一个本地桌面模型网关：集中管理多个模型账号和 API 接口，跨来源选择模型，自动接入 Codex、Claude Code、WorkBuddy、Qoder，并为其他应用创建独立 Key。它提供模型菜单与默认切换、长会话续接、用量与活动记录，以及可预览、可审批、可恢复的配置维修，让模型连接更清楚，日常开发仍留在你熟悉的 Agent 中。
