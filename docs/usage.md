# token-flow 使用指南

适用于当前桌面界面。首次使用可先看 [中文字幕视频](media/quickstart.mp4) 或 [操作动图](media/quickstart.gif)，全部使用虚构数据。

## 1. 添加来源

### 平台账号

打开 **账号授权**，选择平台，点击 **添加账号**。按该平台的浏览器授权、设备码或本地导入流程完成连接。需要补交回调地址时使用授权进度中的输入框，不要公开分享回调。

账号以标签区分，选中后查看模型与可查询额度。平台标题旁的 **刷新** 只更新当前平台。授权时可以浏览其他平台，但不能重复启动授权。

支持的 Codex、Claude、Antigravity 登录可以 **设为本机登录**，并恢复切换前登录。Codex 已接网关时，优先从 **本地 Agent** 的官方账号列表切换，程序会核对凭据并恢复原接口。

### API 接口

打开 **API 接口 → 添加 API**。

| 字段 | 填写方式 |
| --- | --- |
| 名称备注 | 能分辨项目、套餐或入口的名称。 |
| URL | 来源提供的 Base URL，例如 `https://api.example.com/v1`，不要带密码、查询参数或片段。 |
| API Key | 该来源的上游密钥。 |
| 模型名称 | 精确模型 ID；可逐项添加，也可逗号分隔，最多 50 个。 |

点击 **验证并添加**。程序用第一个模型的最小文本请求识别协议，其余模型也必须由此 Key 授权。验证消耗少量额度，不覆盖全部模型、工具、图片或客户端行为。

保存后可查看 / 复制模型列表和接口地址，启用、停用、编辑来源。同类协议可以保存多个入口，重名模型按来源区分。只改名称使用 **保存名称备注**，不重新调用模型。编辑默认隐藏密钥，点击 **显示完整密钥** 才读取；更换密钥有独立按钮。

修改正在使用的接口或停用时提示影响；仍有 Agent、Key 或维修选择引用的来源不能直接删除。

## 2. 给 Agent 配置多个模型

1. 打开 **本地 Agent**，选 Codex、Claude Code、WorkBuddy 或 Qoder。
2. 点击 **选择模型**，已接入时点击 **管理所选模型**。
3. 搜索厂商、账号或模型，展开来源卡片，勾选模型。允许跨卡片多选；同一个请求模型 ID 只能绑定一个来源账号。
4. 点击 **应用所选模型**。程序备份原配置，生成独立受限 Key，并更新模型目录和默认模型。
5. 保存工作、结束生成，在提示中选 **立即重启** 或 **稍后再说**。之后仍可从标题旁重启。
6. 在目标 Agent 选对应模型，发起一次实际请求，到 **活动** 核对结果。

模型列表支持 **设为默认**、用量详情和移除；至少保留一个模型，或 **恢复原配置** 退出网关。切换默认模型不会清空其余已选模型。最近使用记录帮助再次找到模型。

| 客户端 | 操作提示 |
| --- | --- |
| Codex | 完全退出重开刷新菜单。切模型可继续原对话；压缩历史优先本机恢复，恢复不了会提示，不清空原会话。 |
| Claude Code | 当前界面提示自定义模型菜单需要 2.1.242+；旧版可用 `/model 模型ID`。重启可选 VS Code 插件或终端版，终端版需选会话。 |
| WorkBuddy | 重启后在新任务输入框下方选择 `token-flow · 模型`。 |
| Qoder | 此处接入独立应用，重启后选自定义模型；账号授权中的 Qoder IDE 是另一条入口。 |

写入成功只表示配置保存。项目设置、环境变量、客户端版本可能影响调用；模型菜单、网关响应和客户端实际请求分别核对。

## 3. 切回官方账号或原接口

Codex 的官方账号与网关模型在同一页面。点击官方账号先核对凭据，再恢复原接口并切换登录；凭据不完整会拒绝修改。普通模型字段变化允许安全切回，接口或 Key 有外部修改时先核对。

只想退出网关时点击 **恢复原配置** 并重启。原接口和受管设置按备份恢复；配置有外部修改时保留备份并提示，避免覆盖。接入不改变客户端的工具权限。

Codex 切回官方如需迁移压缩记录，先完全退出 Codex；迁移前自动备份。不要上传会话和备份。

## 4. 给其他应用创建 Key

1. 打开 **API 代理 → 创建 Key**，填写名称、用途。
2. 点击 **选择导出模型**，跨来源勾选允许调用的模型。
3. 点击 **生成 Key**，复制网关地址、Key 和精确模型 ID。
4. 按目标应用要求选择协议并测试。不要用上游 Key 代替本地 Key。

详情包含接入信息、支持模型、使用情况。可修改名称 / 用途，或 **管理模型** 更改同一个 Key 的权限；取消不保存。清空权限后该 Key 无法调用模型。新添加的来源不会自动扩大已有权限。

可停用或删除 Key。安全存储可用时能再次显示 / 复制；不能持久保存时需首次生成后妥善保存。后端支持累计 token 预算，当前创建界面默认不限额，来源额度显示不代表已设置预算。

Cursor 此类接入需要外网可访问的 HTTPS 地址，本机 `localhost` 无法直接用于远程验证；程序不自动发布公网服务。

## 5. 用维修师傅解决问题

右下角 **维修师傅** 和 Agent **维修** 打开同一常驻对话。收起保留对话、输入及正在执行的任务；中止使用 **停止**，重新开始使用 **新对话**。

先选维修来源与模型，再描述问题。程序核对模型可用性并通过受限工具检查接入，工具结果可以展开。维修模型可以不同于目标 Agent 的模型。

### 无需维修模型的配置修改

点击 **修改 Agent 配置**，选 Agent、来源与模型，点击 **生成修改方案**。展开 **查看要执行的改动**，核对接口、模型及新 Key 权限，点击 **同意并执行**。

写前备份、保留无关设置、写后复读；审批后文件再变化会停止写入。替换成功后撤销旧 Key。上游地址和 Key 在 **API 接口** 保存，不放入对话。

### 转接服务停止时

主应用仍正常时可在维修模型中明确选择已保存的原生 Responses API 来源，走备用通道；不自动换账号。Agent 页面也可恢复原配置。

后端已有独立诊断、持久化记录、npm Codex CLI 升级适配器，当前简化界面未提供完整独立诊断 / 升级检查按钮。旧 P2 截图不能当作现界面入口；能力范围见 [产品说明](product.md)。

## 6. 核对用量与活动

**活动** 展示请求总数、失败数、输入 / 输出 tokens、最近状态和备份中的切换记录。请求统计只覆盖本次运行，缺失用量显示未知，不补造数据。

模型详情按相关受管 Key 汇总；API 卡片按来源汇总；账号详情按同平台模型合计，不能当作每个同类账号的账单。Key 累计用量与本次运行活动统计口径不同。

**设置** 可以启动、停止、重启网关、刷新额度、看运行日志。反馈前去除账号、Key、回调参数、请求正文和本机路径。

## 常见问题

| 现象 | 处理 |
| --- | --- |
| 有账号没模型 | 启用账号并刷新当前平台，核对模型权限。额度查不到不一定是授权失效。 |
| API 文本验证通过，Agent 仍失败 | 核对客户端选中模型、协议、工具和上下文；最小检测未覆盖这些能力。 |
| 模型菜单不更新 | 完全退出重开目标 Agent，检查版本及项目配置覆盖。 |
| 来源不能删除 | 先移除 Agent、Key 和维修选择中的引用。 |
| 写操作超时 | 刷新状态核对结果，再决定下一步，避免重复写入。 |
| 读取或测试卡住 | 取消请求，核对网关、网络和代理。 |
| 来源拒绝单次请求 | 比较同账号模型的新会话、工具和上下文，保留真实错误，不据此判断整个渠道不可用。 |
